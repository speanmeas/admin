## Class Layer Style

| Layer | Name        |
| ----- | ----------- |
| 1     | Attribute   |

| 3     | Design      |
| 4     | Function    |

## Dart

### StatefulWidget

A widget that has **mutable** state.

Structure:

- **main** — entry point
- **StatefulWidget constructor** — used to pass data
- **StatefulWidget state** — used for design and interaction

### StatelessWidget

A widget that does **not** have mutable state.

Structure:

- **main** — entry point
- **StatelessWidget constructor** — used to pass data and design

## Folder Structure: Core / Features

- **Core** — the main folder that contains all the core features of the application.
- **Features** — the folder that contains all the features of the application.

### Feature Contents

- Form
- Widget
- Dialog
